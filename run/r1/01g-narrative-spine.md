## Narrative Spine: 奕境DH1北京上市传播

```yaml
NarrativeSpine:
  core_tension: "所有智能SUV都在比谁更聪明，却没有一个站出来说：我最在乎你全家人的安全。"

  emotional_arc:
    - state_1: 焦虑/疲惫    # 面对满街"旗舰SUV"，选择困难，信任缺失
    - state_2: 好奇/关注    # "东风+华为"这个组合，央企第一次认真造智能车
    - state_3: 体验/信服    # 亲身感受DH1，原来安心是可以被"做出来"的
    - state_4: 归属/骄傲    # 成为奕境车主，"我选择把家人交给靠谱的人"

  narrative_transitions:
    - from: 焦虑/疲惫
      to: 好奇/关注
      trigger_types:
        - "打破品类疲劳的反差信号"（如"75家全球供应商为你家造一辆车"）
        - "权威信任转移"（如东风56年造车+华为全栈技术，不是新势力PPT）
        - "社交圈层共振"（如企业高管/专业人士朋友圈推荐）
      failure_modes:
        - "信息淹没"——北京每天上百条汽车广告，奕境作为新品牌难以穿透
        - "品牌无感"——消费者对"又一家新势力"的集体麻木
        - "华为疲劳"——认为"又一个华为合作品牌，跟问界没区别"
      lead_requirements:
        - "必须用非汽车行业的语言破圈"（如"全球顶级供应商为你定制的移动客厅"）
        - "必须在第一次接触就建立'央企品质'认知锚"（不是新势力，是东风+华为）
        - "必须提供即时的差异化信号"（问界=华为渠道，奕境=央企智造+全球供应链）

    - from: 好奇/关注
      to: 体验/信服
      trigger_types:
        - "可感知的品质对比"（如DH1 vs 同级竞品的车门关闭声/座椅缝线/NVH对比）
        - "家庭场景实测"（北京→阿那亚全家自驾，真实记录智驾/空间/续航）
        - "安全可视化"（底盘透视/碰撞测试录像/华为ADS 5.0紧急避让实测）
      failure_modes:
        - "体验门槛过高"——用户难找到门店/试驾预约流程繁琐
        - "体验不极致"——静态看车+短途试驾无法建立"安心"感受
        - "竞品截胡"——用户在等待试驾期间被竞品更激进的优惠吸引
      lead_requirements:
        - "必须设计'安心试驾'专属路线"（至少1小时，含高速+城市+山路综合路况）
        - "必须创造'家人共同体验'场景"（鼓励带家人一起试驾，儿童安全座椅体验区）
        - "必须产出可传播的体验内容"（试驾后自动生成专属体验报告+视频，社交分享）

    - from: 体验/信服
      to: 归属/骄傲
      trigger_types:
        - "首批车主专属仪式感"（北京区域集中交付仪式+家庭日）
        - "价值观社群认同"（"选择了奕境，就是选择给家人最好的"——车主社群文化）
        - "口碑裂变激励"（老车主推荐试驾奖励机制+车主故事纪录短片）
      failure_modes:
        - "交付体验落差"——承诺的高端服务与实际提车体验不符
        - "社群冷启动"——没有足够的首批车主形成社区氛围
        - "负面口碑放大"——早期产品瑕疵在车主群中被放大传播
      lead_requirements:
        - "必须设计超出预期的交付仪式"（家庭定制礼盒+专属服务顾问+车主欢迎视频）
        - "必须建立专属社群并有专人运营"（首批北京车主群≤200人，专属管家）
        - "必须具备快速响应机制"（用户反馈24小时内闭环处理）

  symbolic_objects:
    - "奕境安全舱"——DH1白车身结构艺术化展示(参考小米SU7车展拆解展示手法)，以透明/剖面形式呈现高强度钢框架+华为智驾传感器矩阵，视觉化传达"双重守护"
    - "北京家庭出行地图"——手绘风格的北京周边家庭自驾路线图(京郊→张家口→阿那亚→草原天路)，标注沿途充电桩/亲子设施/秘境景点，作为到店伴手礼
    - "安心印记"——融合东风双飞燕标识+华为鸿蒙环+家庭三人的原创图形，作为品质双认证的视觉符号，出现在所有传播物料中
    - "75+1"——75家全球供应商+1个你的家庭，数字符号贯穿传播，"75家顶级供应商为1个中国家庭造一辆车"

  narrative_keywords:
    - "安心"——情感主调，差异化于竞品的"智能""科技""豪华"
    - "担当"——央企品质的人格化表达，"这个品牌有担当"
    - "家人"——核心叙事主体不是"驾驶者"而是"全家人"
    - "全球品质"——75家全球供应商的具象化信任背书
    - "中国家庭的旗舰"——品类定义：不是"智能旗舰"，是"家庭旗舰"

  story_world: "奕境·安心护家所"
  # 世界观描述：在这个世界里，一辆好车的标准不是跑多快、多聪明，而是能否让每一个坐在里面的人感到被保护、被在意。
  # 奕境不是造一辆"聪明的车"，而是造一个"移动的家"——用东风56年的造车担当和华为最前沿的智能技术，为每一个中国家庭打造路上最安心的空间。

  protagonist: "北京家庭的守护者"
  # 主角不是品牌，不是产品，而是那个在选择中反复比较、最终决定"把家人交给奕境"的决策者。
  # TA是家庭的"首席安全官"——买车的动力不是自己想要什么，而是想给家人最好的。

  audience_role: "家庭首席安全官"
  # 用户不是被动的"消费者"或"观众"，而是主动的"安全决策者"。
  # 每一次到店、试驾、分享，都是TA在履行"为家人选择最安心出行方案"的职责。
  # 传播不应该是"推销"，而应该是"帮助这位首席安全官做出最好的决策"。

  memory_anchor:
    anchor: "75家全球顶级供应商，只为1个中国家庭造一辆车"
    type: slogan
    memorability_test: "一年后用户是否还能复述'75+1'的叙事，并关联到奕境品牌？——极大概率。数字锚定(75)+情感锚定(1个家庭)形成强记忆钩子。"
```
