# Narrative Spine: 2026奕境DH1北京上市传播

```yaml
NarrativeSpine:
  core_tension: |
    "参数越看越糊涂，但家人坐进去那一秒，你就知道对了。"
    —— 旗舰六座SUV赛道参数同质化，消费者真正的决策锚点是"全家人的体感"

  emotional_arc:
    - 焦虑 (选车困局: 都是旗舰，到底谁是真旗舰？)
    - 好奇 (新答案: 央企×华为双重品控，一种没试过的安全感)
    - 体验 (身体投票: 家人坐进去的那一刻)
    - 确信 (长期主义: 这不是一辆车，是一个可以信赖的家)
    - 归属 (身份认同: 我选奕境，因为我终于知道自己要什么了)

  narrative_transitions:
    - from: 焦虑
      to: 好奇
      trigger_types:
        - 差异化叙事 (不是又一个参数表, 而是"央企×华为"双重信任故事)
        - 竞品空窗期切入 (车展后各家在等交付, DH1做"不等的理由")
        - 反参数轰炸 (用场景替代参数, 用家人体感替代芯片算力)
      failure_modes:
        - 被竞品声量淹没 (理想L9 Livis 5月上市交付抢占先发)
        - "央企造车"被理解为"国企=老旧"
        - 消费者仍陷入参数对比思维
      lead_requirements:
        - 必须在上市前4周建立"不聊参数聊家人"的新叙事框架
        - 必须用可感知的场景(而非参数)证明DH1差异

    - from: 好奇
      to: 体验
      trigger_types:
        - 真实场景试驾 (不是4S店绕一圈, 而是"二环晚高峰+全家京郊一日"双场景)
        - 第三方验证 (75家全球供应商背书/安全实测数据公开)
        - 家庭决策者共同参与 (试驾不只是司机开, 而是全家一起坐)
      failure_modes:
        - 试驾门槛过高(预约难/路线短/只有司机体验)
        - 家庭用户对"央企"的安全信任尚未建立
        - 到店转化链路断裂(试驾后无跟进)
      lead_requirements:
        - 试驾活动必须设计"全家参与"环节, 后排乘客体验优先
        - 必须有第三方安全背书在到店环节即呈现

    - from: 体验
      to: 确信
      trigger_types:
        - 交付仪式感 (首批车主家庭故事/央企"郑重承诺"仪式)
        - 社群认同 (首批100户"首席安全官"车主社群)
        - 长尾内容持续供给 (车主真实自驾路书/安全实测vlog)
      failure_modes:
        - 交付延迟导致信任崩塌
        - 首批车主口碑不及预期
        - 上市后声量断崖式下跌
      lead_requirements:
        - 交付体验必须超越预期(仪式感+实用关怀)
        - 上市后4周必须有持续内容产出(车主UGC+官方跟进)

    - from: 确信
      to: 归属
      trigger_types:
        - 车主身份升级 (从"买家"到"首席安全官")
        - 品牌共创 (OTA投票/路书出版/周边设计)
        - 跨代际共识 (父辈信任+年轻认可, 全家都说好)
      failure_modes:
        - 车主社群沦为"售后群"无互动
        - 共创承诺未兑现被诟病
      lead_requirements:
        - 车主社群必须有持续运营机制(非一次性)
        - 跨代际叙事必须贯穿始终

  symbolic_objects:
    - "安全座椅" (家庭安全的最小单位, DH1航空级座椅的隐喻)
    - "全家人的后排" (不再是司机视角, 而是后排家人的体验)
    - "央企印章 × 华为logo" (双重信任的视觉符号)
    - "京郊路书" (从北京胡同到阿那亚草原天路的路线)

  narrative_keywords: [安心, 家人, 双重信任, 身体投票, 不聊参数]

  story_world: "双重安心宇宙"
  protagonist: "终于知道自己要什么的北京中产父亲"
  audience_role: "用身体投票的家庭决策者" (主动体验, 主动选择, 主动分享)

  memory_anchor:
    anchor: |
      "家人坐进去那一秒"—— 整场传播的唯一核心画面:
      不是芯片算力, 不是零百加速, 而是老婆孩子坐进DH1后排时的那一声"哇"
    type: visual
    memorability_test: |
      一年后, 用户还能不能描述"家人坐进DH1那一刻"的画面?
      能。因为这不是产品参数, 而是一个家庭故事。
    one_sentence_recall: "选车看参数, 买车看家人——奕境DH1, 让全家人用身体投票"
```

- [x] Transitions: 每步有trigger_types + failure_modes + lead_requirements
- [x] Symbolic objects: 安全座椅/全家人的后排/央企印章×华为logo/京郊路书 (均可视觉化)
- [x] Story world: "双重安心宇宙" (央企安心+华为安心)
- [x] Audience role: "用身体投票的家庭决策者" (主动角色)
- [x] Memory anchor: "家人坐进去那一秒" (通过一年测试 — 是家庭故事不是参数)
