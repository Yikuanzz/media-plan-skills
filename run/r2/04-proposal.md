## Architecture Rationale

- **Candidates considered**:
  - **Pattern A 经典招标六章式**: 评审最熟悉的章节顺序，打分表对齐容易；但易显模板化
  - **Pattern H 战役兵棋式**: 以5个上市战役为骨架，每战役含目标/战术/兵力/评估；央企调性契合，但节奏感可能偏硬
  - **Pattern A+H 混合式 (选定)**: 以A模式的评审友好章节为骨架，但将"营销行动"一章改写为H模式的"五大战役"叙述——每个战役是完整闭环(目标/战术/兵力/KPI)，让评审既能快速打分，又能感受到"这是一份有打法的方案"而不是六章填空

- **Pattern picked**: A+H 混合式 — 招标六章骨架 + 战役式行动章
- **Why this fits**: 央企标(bid_or_tender=true)需要评审能快速定位打分维度 → A模式的章节顺序是安全选择；但Spine的核心张力"家人坐进去那一秒"和Lead Pool的12条hotspot-driven leads需要战役级的叙事节奏 → H模式让5个上市阶段(悬念→揭秘→上市→延续→长尾)每个成为完整战役，有明确的能量曲线和dose选择
- **Information-coverage map**: 见下方目录与Coverage Map
- **Sacrifice**: 失去纯H模式的军事硬核感；章节比纯A多一章(7章 vs 6章)；但评审仍然能在5分钟内定位所有打分维度
- **One sentence to evaluators**: "这是一份评审扫得到分、但又不只是六章的方案——每个战役有自己的目标、兵力和KPI。"

## Voice Decision

- **Tone**: 不端着但有温度——央企稳重是底色，家庭温情是笔触，数据证据是骨架。避免"赋能/引领/重新定义"，用"家人坐进去那一秒"这样的具体画面说话
- **Slogan rhythm**: 八字双段主标语(朗朗上口、央企适配) + 各战役子标语(场景化、不押韵、具体动词)
- **Dominant metaphor / center claim**: **"家人坐进去那一秒"**——整场传播的唯一核心画面，不是芯片算力不是零百加速，而是老婆孩子坐进DH1后排时的那一声"哇"
- **Visual key (告诉设计师)**: 暖色调(琥珀金+象牙白)为主，深蓝(央企色)为底；镜头感偏向"从家人视角看后排"而非"从车外看整车"；风格关键词：温暖/真实/有质感/不炫技
- **What this voice is NOT**: 不是互联网营销的"发疯文学"；不是传统车企的"参数+口号"；不是4A广告公司的"文学腔+空洞视觉"
- **Surface mechanics picked (6项)**:
  1. **双层页眉**: 招标方案需要快速识别"这是哪一页"，央企评审习惯这种格式
  2. **八字双段主标语**: 央企+家庭调性适配，朗朗上口
  3. **痛点-卖点对应表**: DH1有多个产品卖点(激光雷达/航空座椅/75供应商/增程续航)需要清晰映射到客群痛点
  4. **传播标题清单**: 5个战役各有内容输出需求，需要具体标题候选给评审看
  5. **阶段四要素卡**: S级活动(世界杯包厢/京郊路书/三代人座驾)需要展开到能签合同的颗粒
  6. **章末小结**: 行动章(第4章)信息量大，需要小结帮助评审消化
  - **故意不用**: SWOT四象限(竞争分析核心是时间窗口而非二维矩阵)、客群三档分类(客群是连续谱而非三档)、章扉页大开大合(章节7个已偏多，用双层页眉即可)

# 第1章 命题与破局

> 【评分维度：创新性 D1 / 竞品对标 D3】

---

奕境DH1是北京车展后六座旗舰赛道最值得关注的新答案。但2026年6月的北京市场，最大的敌人不是竞品，而是"181台首发车制造的参数噪音"。消费者看了一堆参数，反而更不知道怎么选了。

我们的命题不是"怎么让消费者记住DH1的参数"，而是**"怎么让消费者不用看参数就能做决定"**。

## 1.1 市场判断

| 指标 | 数据 | 来源 |
|---|---|---|
| 2026北京车展首发车 | 181台创纪录 | ME-001 |
| 六座旗舰SUV竞品价格带 | 21.98万-65.98万 | CL-001~CL-004 |
| 2026年6月核心节点 | 世界杯(6/11-7/19) / 618(6/1-6/18) / 绿心音乐节(5/29-6/7) | HS-001/HS-002/HS-006 |
| 行业趋势 | 反内卷整治→价值战替代价格战 | TR-001, ME-004 |

**一句话洞察**: 六座旗舰赛道参数已经同质化到"看参数看不出区别"，消费者真正的决策锚点从参数转移到了"全家人的体感" [ME-006, AU-001]。这意味着DH1不需要在参数上赢——需要在场景体验上赢。

## 1.2 竞争空当：车展后的"空窗期"

| 竞品 | 车展动作 | 展后状态 | DH1空当 |
|---|---|---|---|
| 问界M9 | 全新一代发布 49.98万起 | 等交付 | DH1现在就能试 [CL-001, HS-008] |
| 理想L9 Livis | 5/15上市交付 | 已交付但声量占先 | DH1用场景体验差异化 [CL-002] |
| 零跑D19 | 极致性价比21.98万起 | 已交付 | DH1用品质叙事差异化 [CL-003, TR-002] |
| 智己LS8 | 全线控四轮转向 | 声量较弱 | DH1用家庭场景截流 [CL-004] |

**竞品共性弱点**: 过度依赖车展流量，展后进入"等价格/等交付"空窗期；营销仍以参数对轰为主，场景化体验不足 [CL-005, CL-006, TR-003]。

**一句话洞察**: 车展后各家在等，DH1不用等——"不等的理由"本身就是最好的切入角度 [HS-008]。

## 1.3 本品价值：双重品控

| DH1核心卖点 | 证据 | 一句话 |
|---|---|---|
| 896线双光路激光雷达 | PV-001 | 量产车最高线数，智驾硬件天花板 |
| 2+2+2航空级座椅 | PV-002 | 不是座位，是家人的头等舱 |
| 75家全球供应商 | PV-003 | 宁德时代/博世/米其林/福耀/采埃孚 |
| 双重品控(华为ICT+东风整车) | PV-004 | 央企造车56年 × 华为零缺陷体系 |
| 增程版1200km续航 | PV-005 | 北京到阿那亚来回不用充电 |
| 鸿蒙座舱全家娱乐 | PV-005 | 后排大屏+多屏联动，车里能看世界杯 |

**一句话洞察**: "央企品质+华为科技"是奕境独有的叙事——其他新势力要么是互联网造车(理想/零跑)缺乏制造底蕴，要么有制造但缺科技(传统车企)。奕境两个都有 [PV-006, TR-002]。

> 【评分维度：竞品对标 D3 / 品牌契合度 D4】

---

北京的购车者和其他城市不一样。摇号、限行、通勤距离长——这里的选车不是"要不要买"，而是"好不容易摇到号，一步到位买什么"。

# 第3章 核心策略：身体投票

> 【评分维度：品牌契合度 D4 / 方案逻辑性 D5】

---

**主标语**: 家人坐进去，你就知道了

这个标语不用"引领""重新定义""颠覆"——它只说了一件事：别再看参数了，让家人坐进去试试。

## 3.1 核心张力

> "参数越看越糊涂，但家人坐进去那一秒，你就知道对了。" [Narrative Spine core_tension]

这不是一句广告语，而是整个传播的唯一核心画面。整场传播——从5月的悬念到8月的长尾——都在为这一个画面服务。

## 3.2 情绪路线图

消费者的决策不是一步到位的，而是一条5步情绪迁移路线：

```
焦虑(选车困局) → 好奇(新答案) → 体验(身体投票) → 确信(长期主义) → 归属(身份认同)
```

每一步都有具体的trigger和失败预案 [Narrative Spine transitions]：

| 情绪迁移 | Trigger | 失败风险 | 应对 |
|---|---|---|---|
| 焦虑→好奇 | 差异化叙事(央企×华为双重信任) | 被竞品声量淹没 | L011"不等了"切入空窗期 |
| 好奇→体验 | 真实场景试驾(全家参与) | 试驾门槛过高 | L008音乐节零门槛体验 |
| 体验→确信 | 交付仪式感+车主故事 | 交付延迟信任崩塌 | L009总师IP持续沟通 |
| 确信→归属 | 车主身份升级(首席安全官) | 社群沦为售后群 | L005挑战赛持续UGC |

## 3.3 打法总览

用一个隐喻贯穿全案：**"双重安心宇宙"**——央企安心(东风56年造车品质) + 华为安心(乾崑智能科技)。每一场战役都在这个宇宙里发生。

5个战役按能量曲线分布：悬念期(40)→揭秘期(70)→上市期(100)→延续期(60)→长尾期(20)。峰值只出现一次，在上市期(6/8-6/21)，叠加世界杯开幕和父亲节。

**选址/部署**:
- 拍摄地点：老北京胡同(前门/南锣鼓巷) + 国贸CBD + 望京中产社区 [G4, G3, G5]
- 投放渠道：微信视频号(主) + B站(深度) + 抖音(切片) [C11, C6, C3]
- 户外大屏(国贸/三里屯)为crazy_dose选项，上市期可视预算启用 [C9]

**内容脚本骨架**:
- 开场(0:00-0:15): 父亲坐在老桑塔纳里，说"当年这车就是家里的头等舱"

**KPI**: TVC播放1000万+，纪录片完播率40%+，知乎讨论500+，情感共鸣指数8.5+

**预算**: S级 — 制作费(含拍摄/后期) + 线上投放(视频号/B站/抖音) + 户外大屏(可选)。总预算区间 80-150万
