# Phase: Intake

## Purpose

Normalize the brief into a structured intake document. Block until
research-start fields are present and non-placeholder.

## Required Reads

- `./phases/pre-brief-search.md`
- `./shared/pre-brief-source-map.md`
- `./shared/brief-intake-template.md`

## Inputs (must be ready)

- Pre-brief phase status is resolved: `used` | `skipped` | `inconclusive`.
- When resuming from disk, read `{artifact_root}/00-pre-brief.md` for the resolved Pre-brief blocks (or use the in-session emission if that file is not present yet).

## Rules

- Do not backfill required intake fields (`./shared/brief-intake-template.md`) from pre-brief hints, defaults, or assumptions (see global **NO SPECULATIVE BACKFILL** in `SKILL.md`).
- When `status = used` or `inconclusive`, echo the resolved `## Pre-Brief Search Context` and `## Inspiration Hints` blocks before intake summary (reuse verbatim or paste from Pre-brief output).
- When `status = skipped`, omit Pre-Brief blocks and proceed straight to intake summary.

## Action

1. If pre-brief was `used` or `inconclusive`, paste or restate Pre-Brief output blocks first.
2. Normalize user input into `## Intake Summary`.
3. Set `## Intake Status` to `ready` or `blocked`.
4. If blocked, list only the missing research-start fields.
