# 3md Alignment Checklist

Use this checklist during `Phase: Proposal` self-check to verify output matches `3.md` delivery intent.

## Module Coverage

- Module 1 Task Thesis exists with:
  - core marketing proposition
  - three core tasks
  - one declaration slogan
- Module 2.1 includes Product Spec Table with传播感 language translation (parameters → user-perceivable benefits).
- Module 2.2 includes national track-level analysis (3-year sales trend + powertrain breakdown) and regional-vs-national comparison.
- Module 2.3 includes three-tier competitor classification (核心/重点/延展) and image benchmark (形象对标).
- Module 2.5 includes per-segment 用车场景, 关注要点, and 情感诉求.
- Module 3.1 includes 品牌基础层 (4 dimensions) → 痛点解决层 (3 propositions with solutions) → 产品目标层 (market-role sentence).
- Module 3.3 includes Core Impact Strategy with three directions (声量传播/出行场景/目标客群转化), each with strategic内涵 and >=2落地动作 examples.
- Module 3.4 includes Three-Stage Rhythm Framework + Marketing MAP (6 columns) + Communication MAP (5 columns).
- Module 4 includes detailed action cards with naming, execution, and conversion closure.
- Module 4 Phase 3 includes三大活动类型: 口碑传递 (KOC salon/content/spread chain), 试驾价值体验 (road condition/static-dynamic chapters/seamless close), 网点销售促进 (policy/group buy/livestream/store media).
- Module 4 Phase 3 demonstrates 螺旋上升永动机 logic: 引客→下单→传播→引新客.
- Module 5 centralizes KPI and governance.
- Module 6 service team section is present or correctly skipped.

## Delivery-First Checks

- At least one owned launch event includes:
  - site recommendation (main + backup)
  - on-site layout
  - core run sheet
  - lead capture + handoff
  - on-site conversion trigger
- Industry trade show is not primary launch storyline.

## Communication Checks

- Phase 2 includes N-7/N/N+3 communication table.
- Platform matrix differentiates Douyin, Xiaohongshu, Dongchedi/Autohome, Video Account, Weibo.
- KOL/KOC plan is layered and role-specific.

## Style Checks

- Chinese punchy headings are used.
- Competitor responses are action statements, not parameter tables.
- Activity descriptions include atmosphere/emotion language.
- KPI appears in Operations chapter, not scattered in action cards.
- Evidence markers are used in Insight only.
