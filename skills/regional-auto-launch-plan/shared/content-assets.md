# Content Assets

Use this contract in `Phase: Action` and `Phase: Proposal` to keep content planning tied to stage cards and platform roles.

## Required Output Shape

```md
## Content Assets

### Long-form
- Name:
- Core narrative:
- Primary platform:
- Phase window:

### Mid-form
- Name:
- Cadence or episode structure:
- Primary platform:
- Phase window:

### Short-form
- Program name:
- User or creator action:
- Primary platform:
- Burst or sustained:
```

## Rules

- At least one named line is required for long/mid/short tiers.
- Every stage in `Action Playbook` should map to at least one asset line.
- At least three platforms must include concrete title examples.
- Generic placeholders (for example `KOL seeding`, `online promotion`) do not pass as asset names.
- Proposal chapter `4` should reference asset names when describing stage cards.
