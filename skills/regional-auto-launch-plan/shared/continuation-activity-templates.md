# Continuation Activity Templates (Phase 3)

Use this contract in `Phase: Action` when building Phase 3 (延续转化期) activity cards. These templates ensure the three activity types required by the brief are fully expanded, not compressed into generic descriptions.

## Core Logic (mandatory)

Phase 3 must follow a **螺旋上升永动机** logic:

1. 前期引来的客户 → 让他下单
2. 下单客户 → 转化为传播声量
3. 传播声量 → 引来新客户
4. 新客户 → 继续引导下单
5. 犹豫客户 → 持续培育，促进最终成交

## Phase 3 Dispatch Integration

When dispatching sub-agents for Phase 3 pillars:

1. `3-offline-conv`: use **Template C** (网点销售促进) as primary form, **Template A** (口碑传递) as alternative candidate.
2. `3-offline-trial`: use **Template B** (试驾价值体验) as primary form.
3. `3-online`: use **Template A** (口碑传递) online variant as primary form.

Each sub-agent dispatch prompt must include a reference to the relevant template and its mandatory fields.
