# Core Theme Derivation

Use this contract in `Phase: Strategy` after Insight passes.

## Required Strategy Blocks

- `3.1 Differentiated Value Presentation` — two-part output:
  - **Input foundation** (from Insight `2.1`): functional / emotional / identity three-layer value analysis.
  - **Strategy presentation** (3.md aligned): 品牌基础层 → 痛点解决层 → 产品目标层. See mapping rules below.
- `Slogan Derivation Chain`.
- `Core Theme` with traceable source explanation.
- Three stage sub-themes (pre-heat / launch / sustain) that are distinct but aligned.

### Mapping: Insight Value Layers → Strategy Presentation

| Insight Layer (input) | → | Strategy Layer (output) |
|---|---|---|
| Trust value + Functional value | → | **品牌基础层**: brand endorsement logic (parent company / co-creation partners / tech source / production quality / service channel). Expand across 4 dimensions: 产品定义 / 技术研发 / 品质生产 / 服务渠道. |
| Functional value + Audience pain points | → | **痛点解决层**: 3 core value propositions (e.g. 全尺寸 / 高智能 / 超安全), each with concrete solution evidence, not slogan. |
| Emotional value + Identity value | → | **产品目标层**: one传播力 sentence defining the product's ultimate market role (e.g. "成为高品质家庭的移动主场"). |

## Slogan Derivation Chain (mandatory)

The chain must explicitly include and connect all three dimensions:

1. `Brand anchor` - what the brand can credibly claim in this region.
2. `Audience insight` - what the target audience in this region actually cares about.
3. `Product value` - what the product can prove (not abstract adjectives).

Output shape:

```md
## Slogan Derivation Chain
- Brand anchor:
- Audience insight:
- Product value:
- Derived slogan:
- Why this slogan is valid in this region:
```

## Core Theme Traceability (mandatory)

`Core Theme` must be explainable from evidence, not invented by style preference.

Output shape:

```md
## Core Theme
- Core Theme:
- Source trace:
  - Insight evidence used:
  - Market/product/audience links:
- Why it can hold across all 3 stages:
```

## Dual-Axis Balance Check (mandatory)

`Core Theme` and `Derived slogan` must pass both axes at the same time:

- Axis A (technology/performance): answer `why this car leads` with provable technical or engineering strength.
- Axis B (`<primary-buyer-identity>`): answer `why this identity finds this car meaningful` with concrete lived scenes.

`<primary-buyer-identity>` must be sourced from Insight (`2.5 Audience Segmentation` / `Insight Handoff Pack`), not assumed in Strategy.

If output is single-axis (Axis A only), auto-repair before phase pass:

1. Add identity-directed wording in slogan and explanation.
2. Add emotional anchors that match the selected buyer identity.
3. Replace abstract emotion wording with concrete scenarios in that identity's world.

Output shape:

```md
## Dual-Axis Balance Check
- Axis A evidence (technology/performance):
- Axis B identity selected: <value + source ref>
- Axis B evidence (identity/emotion):
- Is slogan dual-axis balanced: yes/no
- If repaired, what was changed:
```

Output shape:

```md

<one commanding strategic phrase, e.g. "极致压强 饱和攻击">
```

## Gate Criteria

- Fail if any Slogan Derivation Chain dimension is missing.
- Fail if the slogan cannot be traced back to brand + audience + product.
- Fail if Core Theme has no source trace.
- Fail if stage sub-themes are duplicate phrasing or conflict with Core Theme.
- Fail if Three-Stage Rhythm Framework table is missing or any cell is empty.
- Fail if Marketing MAP table is missing or any cell is empty.
- Fail if Communication MAP table is missing or has generic labels instead of specific titles/platforms.
- Fail if `Core Impact Strategy` is missing any of the three directions.
- Fail if any direction has no strategic内涵 explanation.
- Fail if any direction has fewer than 2落地动作 examples.
- Fail if overall strategy declaration is missing.
- Fail if `Dual-Axis Balance Check` is missing.
- Fail if Axis B has no concrete scene tied to selected buyer identity.
