# Core Theme Derivation

Use this contract in `Phase: Strategy` after Insight passes.

## Required Strategy Blocks

- Three-layer value system (functional / emotional / identity).
- `Slogan Derivation Chain`.
- `Core Theme` with traceable source explanation.
- Three stage sub-themes (pre-heat / launch / sustain) that are distinct but aligned.

## Slogan Derivation Chain (mandatory)

The chain must explicitly include and connect all three dimensions:

1. `Brand anchor` - what the brand can credibly claim in this region.
2. `Audience insight` - what the target audience in this region actually cares about.
3. `Product value` - what the product can prove (not abstract adjectives).

Output shape:

```md
## Slogan Derivation Chain
- Brand anchor:
- Audience insight:
- Product value:
- Derived slogan:
- Why this slogan is valid in this region:
```

## Core Theme Traceability (mandatory)

`Core Theme` must be explainable from evidence, not invented by style preference.

Output shape:

```md
## Core Theme
- Core Theme:
- Source trace:
  - Insight evidence used:
  - Market/product/audience links:
- Why it can hold across all 3 stages:
```

## Gate Criteria

- Fail if any Slogan Derivation Chain dimension is missing.
- Fail if the slogan cannot be traced back to brand + audience + product.
- Fail if Core Theme has no source trace.
- Fail if stage sub-themes are duplicate phrasing or conflict with Core Theme.
