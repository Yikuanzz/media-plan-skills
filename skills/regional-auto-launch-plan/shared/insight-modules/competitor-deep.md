# Insight Module: Competitor Deep

## Objective

Build a competitor deep-dive for core and secondary competitors, with actionable implications.

## Mandatory Scope

- Analyze each major competitor by the `5-dimension (5维)` frame:
  1. Positioning
  2. Marketing approach
  3. Channel strategy
  4. Trust path
  5. Counter-strategy for our plan (multi-sentence paragraph)
- For each competitor brand, include `2-3` recent campaigns.

## Evidence Requirement

- Module pass requires >=2 evidence sources.
- Campaign references should prioritize recent windows (ideally last 12 months).

## Output Template

```md
## 2.3-2.4 Competitor Deep

### [Competitor brand]
- Positioning:
- Marketing approach:
- Channel strategy:
- Trust path:
- Counter-strategy (multi-sentence):

#### Recent campaigns (2-3)
1. [campaign + date + source]
2. [campaign + date + source]
3. [optional campaign + date + source]

### Evidence
1. [source + key point]
2. [source + key point]
```

## Gate

- Fail if any competitor misses one of the `5-dimension (5维)` dimensions.
- Fail if any competitor has fewer than 2 recent campaigns.
- Fail if evidence count is below two sources.
