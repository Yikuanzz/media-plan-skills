# Launch Execution Template

Use this contract in `Phase: Action` for delivery-first launch design, especially `4.2 Phase 2 Launch Burst`.

## Purpose

Convert strategy into an executable launch package that can be handed to local teams without extra interpretation.

## Hard Gate

- Fail if Phase 2 lacks any block from A-E.
- Fail if site recommendation has no backup option.
- Fail if run sheet misses one of the five fixed nodes.
- Fail if communication plan has no platform differentiation.
