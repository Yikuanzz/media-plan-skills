# Private-Domain Operations

Use this contract in `Phase: Operations` for retention, referral, and lifecycle communication in low-cost regional launch programs.

## WeChat Private Domain Architecture

### Topology

公众号 -> 视频号 -> 企微 -> 社群 -> CRM

#### Topology handoff rule

- Every node must have owner, SLA, and data-sync method.

### Node responsibilities

#### Minimum node outputs

- inbound handling
- status update
- escalation path

- Official Account: policy/content hub and form entry.
- Video Account: live and short-form engagement.
- WeCom: one-to-one follow-up and conversion servicing.
- Communities: owner interaction and referral growth.
- CRM: identity, stage, and action logging.

## Post-Purchase Onboarding Journey

### D0 to D90 touch cadence

#### Cadence integrity rule

- Missing touchpoint requires explicit fallback action.

| Window | Core goal | Touchpoint |
| --- | --- | --- |
| D0 | confidence and next steps | welcome message + delivery checklist |
| D1-D7 | reduce uncertainty | feature guide + service intro |
| D8-D30 | usage activation | scenario tips + first review request |
| D31-D60 | advocacy seed | community invitation + referral cue |
| D61-D90 | loyalty baseline | maintenance reminder + owner benefits |

### Content toolkit

#### Toolkit maintenance

- Keep one evergreen set and one campaign set.

- quick-start video
- maintenance FAQ
- policy reminder card
- referral invitation template

## Owner Community Playbook

### Rhythm

#### Rhythm execution note

- Weekly and monthly actions need named owners.

- daily: micro interaction and service Q&A
- weekly: themed content or owner story
- monthly: lightweight offline/online owner event

### Activity metrics

- active user ratio
- participation rate
- referral lead count
- service satisfaction pulse

## Referral Program Design

### Three-level model

#### Reward control rule

- Reward rules must be transparent and auditable.

- Basic: referral registration reward
- Successful: confirmed order reward
- Ambassador: multi-order or sustained referral reward

### Attribution minimum fields

- referrer id
- referred lead id
- conversion stage
- reward status

## Customer Lifecycle Communication Calendar

### Seven lifecycle stages

#### Stage transition rule

- Transition must be driven by observable customer behavior.

1. first lead
2. warm nurture
3. test-drive arranged
4. order pending
5. post-order waiting
6. post-delivery onboarding
7. owner advocacy

### Touch matrix requirements

- channel
- message objective
- cadence
- owner
- success KPI

## Churn Prevention and Re-Engagement

### Early warning signals (6)

#### Alert handling window

- Each alert should trigger owner response within 24h.

1. consecutive message non-response
2. booking cancellation trend
3. price objection repetition
4. community silent period
5. service complaint signal
6. competitor switching intent mention

### Re-engagement campaign types (4)

1. policy refresh campaign
2. scenario value campaign
3. service-confidence campaign
4. owner-referral reactivation campaign

## Gate for Operations use

- Fail if WeChat topology or node ownership is incomplete.
- Fail if D0-D90 onboarding cadence is missing.
- Fail if referral model and lifecycle communication matrix are missing.
